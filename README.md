# Pockit | A payments application utilizing wallet
Pockit is a simple Wallet application to offload money from the bank using webhooks, and transact with other people with ease.

## Features

- OnRamp Money from Bank to Wallet
- Implementation of mock webhooks
- P2P Transfer
- Session Management using NextAuth
- Dashboard displaying recent Onramp and P2P transactions history

## Upcoming

- OffRamping wallet money back to bank using redis queues
- OTPs when doing payments
